# Mi página web sencilla

Este proyecto es una pequeña página web creada con HTML, CSS y JavaScript!!!!!!!!!

## Descripción

La página incluye:
- un diseño minimalista con fondo degradado
- una tarjeta central con texto y botón interactivo
- un reloj analógico en la esquina inferior derecha
- un reloj digital dentro de la tarjeta

## Estructura del proyecto

```text
my-web/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Archivos principales

- `index.html`: estructura de la página.
- `styles.css`: estilos visuales y diseño.
- `script.js`: lógica del botón y del reloj.

## Cómo abrir el proyecto

1. Abre la carpeta `my-web`.
2. Haz doble clic en `index.html`.
3. La página se mostrará en tu navegador.

También puedes abrirlo desde un servidor local si prefieres, por ejemplo con Live Server en VS Code.

## Personalización

Puedes modificar:
- colores y tipografías en `styles.css`
- contenido del texto en `index.html`
- comportamiento del reloj y botón en `script.js`

## Requisitos

No necesitas instalar dependencias ni frameworks. Solo necesitas un navegador moderno.
